System Architecture: Oddity Brainstorming Agent1. Executive SummaryOddity is a Chrome Extension designed to turn Google Docs into an interactive brainstorming canvas. It uses a specialized trigger (@Oddity 1 start) to initialize a floating AI interface powered by Claude 3.5/3.6 Sonnet.2. Technical StackRuntime: Chrome Extension Manifest V3Frontend: React + Tailwind CSS (bundled via Vite)Isolation: Shadow DOM (to prevent Google Docs CSS pollution)LLM Engine: Anthropic Claude API (Sonnet 4.6)Communication: RxJS or standard Chrome Message Passing for streaming3. Core ModulesA. The Observer (Content Script)Google Docs does not use standard HTML text areas; it uses a custom internal model.Trigger Detection: Monitors the keydown and input events on the .kix-editor or [contenteditable="true"] surface.Command Parser: Regex-based listener for @Oddity 1 start.Context Scraper: Uses the Google Docs "Document AI" or a fallback "Select All + Copy" buffer strategy to grab the existing text to provide context to Claude.B. The Floating UI (Shadow DOM)Container: A div injected into the document.body.Encapsulation: Uses element.attachShadow({mode: 'open'}) to ensure the floating chat bubble doesn't inherit Google’s styles or break Google’s UI.Draggable Logic: A custom hook to allow the user to move the text field anywhere on the screen.C. The Bridge (Background Service Worker)Secure API Handling: Stores the Anthropic API Key in chrome.storage.local.Streaming Proxy: Receives user prompts from the Content Script, calls the Anthropic API with stream: true, and pipes chunks back to the UI.Context Window Management: Prunes the document text and chat history to stay within Claude’s token limits.D. The Writer (Injection Engine)Text Insertion: Implements a "Typewriter" effect by simulating keyboard events or using the Google Docs google.script.run (if using an Apps Script companion) to insert AI-generated suggestions directly into the doc at the cursor position.4. Data Flow (Sequence)User types @Oddity 1 start in the Doc.Content Script detects the string $\rightarrow$ hides the typed text $\rightarrow$ renders the Floating Chat Window.UI prompts: "What's the topic, idea, or problem you want to think through?"User replies in the Floating Window.Background Worker sends: [System Prompt] + [Full Doc Text] + [User Query] to Claude.Claude streams the response $\rightarrow$ Background $\rightarrow$ Content Script UI.User can click "Insert to Doc" $\rightarrow$ Trigger the Writer Module to paste the result.5.
